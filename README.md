# Simple Vault — неделя 9

Учебный проект по Solana и Anchor. В этой неделе продолжил работу над Vault, который был начат на неделе 8. Основная задача — добавить возможность вносить SPL-токены в хранилище и получать за это share-токены.

## Что реализовано

### Неделя 8

В проекте остались функции с предыдущей недели:

- `initialize_vault` — создаёт Vault, token account для хранения токенов и mint для share-токенов.
- `create_user_card` — создаёт отдельную PDA-карточку для каждого пользователя.
- Повторно создать карточку для одного пользователя нельзя.

### Неделя 9

Добавлена функция `deposit`, которая позволяет пользователю внести токены в Vault и получить share-токены.

```rust
deposit(ctx: Context<Deposit>, amount: u64)
```

Как работает депозит:

1. Сначала проверяется, что сумма депозита больше нуля.
2. Рассчитывается количество shares, которое получит пользователь.
3. SPL-токены переводятся с пользовательского аккаунта на token account Vault.
4. Vault выпускает соответствующее количество share-токенов пользователю.
5. Обновляется информация о количестве внесённых токенов и полученных shares.

Количество shares рассчитывается по формуле:

- Если это первый депозит, пользователь получает shares в соотношении 1:1.
- Если в Vault уже есть токены, используется формула:

```text
shares = amount * total_shares / total_tokens
```

Для расчётов используется `u128` и checked arithmetic, чтобы избежать переполнения.

Также добавлены проверки, которые не позволяют внести нулевую сумму или получить 0 shares.

## Пример работы

В тестах проверяется следующая ситуация:

- Пользователь A вносит 100 токенов и получает 100 shares.
- Пользователь B вносит 50 токенов и получает 50 shares.

После двух депозитов в Vault находится:

- 150 базовых токенов;
- 150 share-токенов;
- `total_tokens = 150`;
- `total_shares = 150`.

## Что пока не реализовано

В этой неделе реализован только депозит. Следующие функции будут добавлены в неделе 10:

- `withdraw` — вывод токенов из Vault;
- `burn` — сжигание share-токенов;
- возврат базовых токенов пользователю с помощью CPI и подписи Vault PDA.

## Установка и сборка

Сначала устанавливаем зависимости:

```bash
yarn install
```

Затем собираем программу:

```bash
anchor build
```

## Запуск в Devnet

Для работы с проектом используется Solana Devnet.

Проверить настройки и баланс кошелька можно командами:

```bash
solana config set --url devnet
solana address
solana balance
```

Для развёртывания программы:

```bash
anchor deploy --provider.cluster devnet
```

После успешного деплоя можно запустить тесты:

```bash
yarn test
```

Важно: тесты настроены с параметрами `--skip-local-validator` и `--skip-deploy`, поэтому перед запуском необходимо самостоятельно развернуть актуальную версию программы в Devnet.

Для тестов на кошельке администратора должны быть Devnet SOL, так как он оплачивает создание необходимых аккаунтов и комиссий.
